# SoftwareFJ - Fase 4 (Grupo 2204)

Sistema de gestión y cotización de servicios tecnológicos desarrollado en Python aplicando Programación Orientada a Objetos (POO), herencia, polimorfismo, manejo de excepciones personalizadas e interfaz gráfica en inglés (`tkinter`).

## Estructura del Proyecto
- `excepciones.py`: Excepciones personalizadas para validación de negocio.
- `entidades.py`: Clase abstracta base `Servicio`.
- `servicios.py`: Implementación de servicios concretos (Módulo de colaborador).
- `gestor.py`: Controlador lógico y almacenamiento en memoria (Módulo de colaborador).
- `main.py`: Interfaz gráfica de usuario (GUI) en inglés.
